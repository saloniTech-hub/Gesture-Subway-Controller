# 🎮 AI Gesture-Based Subway Surfers Controller

Control Subway Surfers using hand gestures through a webcam. This project uses computer vision to recognize hand gestures and convert them into keyboard inputs for real-time gameplay.

## 🚀 Features
- Real-time hand tracking
- Finger counting
- Gesture recognition
- Gesture-to-keyboard mapping
- Subway Surfers control using BlueStacks
- Built with Python and MediaPipe

## 🛠️ Tech Stack
- Python
- OpenCV
- MediaPipe
- PyDirectInput

backend/
frontend/

## ✋ Gesture Controls

| Gesture | Action |
|---------|--------|
| ✊ Fist | Roll |
| ☝️ Index Finger | Move Left |
| ✌️ Two Fingers | Move Right |
| 🖐️ Open Palm | Jump |
